# 🎵 Emotion Detection and Music Recommendation System

## 📌 Project Overview

This project detects human emotions using facial expressions and recommends songs based on the detected mood.

---

## 🚀 Features

* 🎭 Emotion Detection using CNN model
* 📷 Image/Webcam input
* 🎶 Music Recommendation based on emotion
* 🌐 Web interface using HTML, CSS, JavaScript

---

## 🧠 Technologies Used

* Python
* Flask
* TensorFlow / Keras
* OpenCV
* HTML, CSS, JavaScript

---

## 📥 Setup Instructions

1. Download dataset and model from the above link
2. Extract the files
3. Place them inside your project folder

Final structure should look like:

```
project-folder/
│── app.py
│── dataset/
│── models/
│── static/
│── templates/
```

---

## ▶️ How to Run

1. Open terminal in project folder

2. Create virtual environment (optional):

```bash
python -m venv venv
venv\Scripts\activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

5. Open browser and go to:

```bash
http://127.0.0.1:5000/
```

---

## ⚠️ Notes

* Ensure dataset and model folders are correctly placed
* Check file paths in `app.py` if errors occur
